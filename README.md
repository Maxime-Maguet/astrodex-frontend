# Astrodex - Frontend 🚀

Projet mobile développé avec Expo (SDK 54).

## 🛠️ Installation
1. Clonez le dépôt sur la branche dev :
   `git clone -b dev [URL_DU_REPO]`
2. Installez les dépendances avec **Yarn** :
   `yarn install`

## 📱 Lancement
Pour lancer l'application avec le cache vidé :
`npx expo start -c`

## ⚠️ Notes importantes
- Utilisez uniquement **Yarn** pour éviter les conflits de versions.
- Assurez-vous d'être bien sur la branche **dev**.
